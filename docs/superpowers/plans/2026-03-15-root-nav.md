# Root Nav — Login, Register & CTA Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "Iniciar sesión" and "Reporte gratis" links to the RootLayout nav bar alongside the existing "Registro" link.

**Architecture:** Single file change to `src/layout/root.tsx`. The two ghost nav links use the existing `NavigationMenuLink asChild` + `NavLink` pattern. The primary CTA uses `Button asChild` directly inside `NavigationMenuItem` (no `NavigationMenuLink` wrapper) to avoid style conflicts. `ml-auto` on `NavigationMenu` right-aligns the group.

**Tech Stack:** React 19, React Router 7 (`NavLink`), Shadcn/UI (`NavigationMenu`, `Button`), Tailwind CSS v4.
