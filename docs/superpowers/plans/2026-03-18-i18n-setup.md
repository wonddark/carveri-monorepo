# i18n Setup Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install and configure i18next with English/Spanish support, wire a language toggle into the app header, and populate all translation files with extracted strings from the current codebase.

**Architecture:** All translation JSON files are imported statically in `src/lib/i18n.ts` and registered with i18next. The `i18next-browser-languagedetector` plugin handles localStorage → browser detection → `en` fallback. A `LanguageToggle` component in `AppHeader` calls `i18next.changeLanguage()` to switch languages.

**Tech Stack:** i18next 24.x, react-i18next 15.x, i18next-browser-languagedetector 8.x, React 19, Vite, TypeScript

- [ ] **Step 2: Enable `resolveJsonModule` in `tsconfig.app.json`**

Open `tsconfig.app.json` and add `"resolveJsonModule": true` to `compilerOptions`. This is required for TypeScript to understand `import foo from "path/to/file.json"` static imports used in `src/lib/i18n.ts`.

The `compilerOptions` block should include:
```json
"resolveJsonModule": true
```

```typescript
import { Globe } from "lucide-react";
import i18next from "i18next";
import { useTranslation } from "react-i18next";

export default function LanguageToggle() {
  const { i18n } = useTranslation();
  const currentLang = i18n.language.startsWith("es") ? "es" : "en";

  const toggle = () => {
    i18next.changeLanguage(currentLang === "en" ? "es" : "en");
  };

  return (
    <button
      onClick={toggle}
      className="flex items-center gap-1 rounded-lg bg-slate-100 px-2 py-1.5 text-xs font-semibold text-slate-500"
      aria-label="Toggle language"
    >
      <Globe size={13} />
      {currentLang.toUpperCase()}
    </button>
  );
}
```
