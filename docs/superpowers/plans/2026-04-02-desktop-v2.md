# desktop-v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `apps/desktop-v2` — a desktop-only visual clone of `https://carcheckcub-e8jeqgfr.manus.space/reports/JA4J4VA86RZ079851`, with fresh UI components and mock data.

**Architecture:** Copy `apps/desktop` as scaffold base, strip all UI components and i18n, rebuild the layout shell (Header, Sidebar, MainContent) and all section views from scratch. Types are from `@carveri/shared/types/vehicle-report`; mock data flows through a local `reportLoader` → `transformToSharedReport` → `AppReport`.

**Tech Stack:** React 19, React Router 7, Tailwind CSS v4, TypeScript 5.9, Vite 7, pnpm workspace, Lucide icons

```ts
import type { LoaderFunctionArgs } from "react-router";
import { fetchVehicleReport } from "@carveri/shared/data/api";
import { transformToSharedReport } from "@/lib/transforms";

export async function reportLoader({ params }: LoaderFunctionArgs) {
  if (!params.vin) throw new Response("Not Found", { status: 404 });
  const raw = await fetchVehicleReport(params.vin);
  return transformToSharedReport(raw.data);
}
```
